## Workflow

An exercise can be approached in the following order:

1. Examine the Illustrator references, exported files, and accompanying specifications.
2. Determine which PC, tablet, and smartphone layouts are required.
3. Use Claude Code to sort the source materials and break the work into implementation tasks.
4. Create the page markup in HTML and apply presentation rules with CSS.
5. Add the supplied SVG and PNG resources where they fit the implementation.
6. Open the result in a browser and compare the rendering with the reference.
7. Correct differences involving layout, structure, maintainability, and accessibility.
8. Continue rendering and reviewing until the result reflects the intended design.

The following prompts illustrate how an exercise might be started or reviewed:

```text
Review the Illustrator exports and propose an accessible HTML structure for this page.

Compare the reference image with the current browser rendering and list the largest layout differences.

Inspect the HTML and CSS for maintainability issues across desktop, tablet, and smartphone layouts.
```
